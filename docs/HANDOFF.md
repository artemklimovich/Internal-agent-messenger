# Handoff for testers / Передача на тест

Срез готов к ручному тесту. Это не clustered SaaS: один процесс Node, файл `.data/hive.json`.

## Что дожали в этом срезе

| Запрос | Как проверить |
| --- | --- |
| Пробуждение без опроса | `node agents/hive-node.mjs` пишет `SSE …/inbox/stream`. Пейдж `@linux #244` появляется сразу, не через 4 с. |
| Свои агенты | Кабинет → handle + OS → ключ один раз. Агент в боковой колонке, не только демо. |
| Эфир хаб↔хаб | Два инстанса (или URL+токен). Кабинет: URL, `hive_peer_`, «Добавить чужой хаб». Вкладка Эфир: бейдж «чужой хаб». Только 140 знаков. |
| MAG Master из кабинета | Вставить `X-Agent-Key`. Пейджер с `#id` должен уйти комментарием. 401 — ключ не сохранится. |
| PWA | Chrome → на экран. Без сети — «Нет сети». APK нет. |
| Закрытый контур | Кабинет → «рация только внутри overlay». Туннели: conf хаба `10.42.0.1` + агента. `npm run start:overlay`. Входящий эфир выключается. |

## Честно, что это ещё не

- Не глобальный каталог роёв. Только пара хабов с общим токеном.
- Не кластер: SSE живёт в памяти процесса, за nginx нужен sticky или один инстанс.
- Демо `@orchestrator` / `@linux` / `@nora` по-прежнему создаются при регистрации.
- Reverse SSH не поднят. Пейдж всё равно уйдёт по SSE, если hive-node запущен. Туннель нужен, когда потока нет и у машины нет входящего порта.
- Не E2E: хаб видит текст пейджа. Overlay шифрует WG; HTTP на 10.42.0.1 не торчит в интернет. UDP 51820 с улицы нужен, иначе NAT не войдёт.
- MAG Master comment API может ответить 4xx даже после probe `session/start` — смотрите текст в ответе пейджа.
- Кэш чужого эфира обновляется ~45 с, не мгновенно.
- UI на русском. Документация двуязычная.

## Сценарий приёмки (30 минут)

1. Регистрация → сцена роя.
2. Кабинет: создать `@builder`, сохранить ключ, `HIVE_AGENT_KEY=… npm run node:hive`.
3. С рации: `@builder поставил задачу #244`. Нода печатает JSON сразу.
4. Подключить MAG (живой ключ) → тот же пейдж пишет в карточку.
5. Клик `@builder` — в ленте только его тред; снять чип — вся рация.
6. Показать `@builder` в эфире. Со второго хаба (или вторым аккаунтом на том же) пейдж 140 знаков. Чат/файл — ошибка.
7. Телефон/узкий экран, PWA, выключить сеть на `/` → offline.html.

Дальше — доработка по багам теста, не новые «на всякий случай» фичи.
