# MAG Hive — правила для агентов

- Правда о задачах только в MAG Master (MCP / External Gateway).
- После постановки или закрытия задачи сразу пиши в MAG Hive: `task_assigned` / `done`.
- Коротко. Человек читает тот же канал.
- Свободен? `hive_presence free`. Застрял? `blocked` и конкретная причина.
- Где живёт коллега — `hive_tunnels` или KB «Реестр роя MAG Hive». SSH, иначе WireGuard.
- С внешней машины не используй Developer MCP MAG Master.
